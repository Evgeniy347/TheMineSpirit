- scan — просканировать мир вокруг духа. Параметры: radius: integer 1..32 = 8; filter: string[]. Нужно: ничего. Даёт: обновлена карта блоков, сущностей и контейнеров.
- goto — пройти к заданной точке. Параметры: x*: integer -30000000..30000000; y*: integer -64..319; z*: integer -30000000..30000000. Нужно: точка достижима. Даёт: дух находится в точке.
- chop_tree — срубить деревья. Параметры: species: string = "any"; count: integer 1..256 = 1. Нужно: в радиусе есть подходящие брёвна. Даёт: брёвна срублены; предметы подобраны в инвентарь.
- mine_vein — добыть жилу руды. Параметры: ore: enum any|coal|iron|copper|gold|redstone|lapis|diamond|emerald|quartz|netherite = "any"; count: integer 1..256 = 1; radius: integer 1..32 = 16. Нужно: в радиусе есть подходящая жила. Даёт: руда добыта.
- gather — собрать блоки заданного типа. Параметры: block*: string; count*: integer 1..256; radius: integer 1..32 = 16. Нужно: в радиусе есть подходящие блоки. Даёт: блоки собраны.
- collect_drops — подобрать выпавшие предметы вокруг духа. Параметры: radius: integer 1..16 = 8; filter: string[]. Нужно: в инвентаре есть место. Даёт: предметы по фильтру в радиусе подобраны; предметов по фильтру в радиусе не осталось.
- till — вспахать землю рядом с водой. Параметры: radius: integer 1..16 = 8; count: integer 1..256 = 16. Нужно: в инвентаре есть мотыга; рядом есть вода. Даёт: клетки вспаханы.
- plant_crop — посадить культуру. Параметры: crop*: enum wheat|carrot|potato|beetroot; radius: integer 1..16 = 8; count: integer 1..256 = 64. Нужно: есть семена; есть вспаханная земля. Даёт: культура посажена.
- harvest_crop — собрать зрелый урожай. Параметры: crop: enum any|wheat|carrot|potato|beetroot = "any"; radius: integer 1..16 = 8; replant: boolean = true. Нужно: посевы созрели. Даёт: урожай собран.
- bone_meal — удобрить недозрелые посевы костной мукой. Параметры: crop: enum any|wheat|carrot|potato|beetroot = "any"; radius: integer 1..16 = 8; count: integer 1..256 = 16. Нужно: есть костная мука; есть недозрелые посевы. Даёт: посевы подросли.
- craft — скрафтить предмет. Параметры: item*: string; count*: integer 1..256; radius: integer 1..32 = 16. Нужно: есть материалы и рецепт. Даёт: предмет скрафчен.
- equip — надеть предмет. Параметры: item*: string. Нужно: предмет есть в инвентаре. Даёт: предмет надет.
- withdraw — взять предметы из контейнера. Параметры: container: string = "nearest"; item*: string; count*: integer 1..256; radius: integer 1..16 = 8. Нужно: контейнер доступен. Даёт: предметы в инвентаре; контейнер отсортирован.
- acquire — добыть предмет любым способом. Параметры: item*: string; count*: integer 1..256. Нужно: ничего. Даёт: предмет есть в инвентаре.
- wait — ждать заданное число тиков. Параметры: ticks*: integer 1..6000. Нужно: ничего. Даёт: время ожидания прошло.
