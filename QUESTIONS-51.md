# Вопросы по чеклисту 51 (доска задач на экране J)

Работа продолжена по рекомендациям; ответ меняет только порядок/подписи, не устройство.

1. **Порядок завершённых.** Сейчас — по времени завершения, старые выше (лента событий). Завершённых может
   накопиться много, и активные уедут вниз. Рекомендация: оставить, но открывать экран с фильтром «активные»?
   Или новые завершённые сверху? Сейчас: старые сверху, фильтр по умолчанию «все».
2. **Проваленные и отменённые** показываются в группе «недоступные» со своим статусом в подсказке. Рекомендация:
   так и оставить (prune их скоро снимает).
3. **«Есть инструменты».** У задания доски нет отдельного требования к инструментам — только `requiredItems`
   и зависимости. «Доступно» = статус PENDING, нехватки нет, зависимости выполнены. Рекомендация: так.
4. **Тексты кейсов** (`lang/ru_ru.json`, ключи `theminespirit.board.case.*`) написаны по имени кейса; часть
   угадана (STOCK_CHESTS — «Сделать сундуки», WEAVE_WOOL — «Сделать шерсть», ENCHANT_SHELVES — «Поставить
   книжные полки»). Рекомендация: владелец правит формулировки в json, код трогать не нужно.
