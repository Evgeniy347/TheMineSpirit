## Открытые решения (нужен выбор пользователя)

- [ ] Где живёт ИИ: внешний оркестратор подключается по REST / мод сам зовёт LLM / оба. Рекомендация: оба.

- [ ] Структура репозитория: single-module с пакетами (как сейчас) / multi-module `:core / :mod / :bridge`.
      Рекомендация: multi-module; текущий статус — single-module.
- [ ] Формат наблюдения: сводка (census) / срез-сетка (ASCII) / точечные запросы. Рекомендация: сводка + точечные.
- [ ] Модель LLM: облако (OpenAI-совместимое) / локальная (Ollama). Рекомендация: абстракция + локальная по умолчанию.
- [ ] Границы P1: что считаем первым играбельным демо. Рекомендация: 1 дух, `follow` + `chop_tree`.
