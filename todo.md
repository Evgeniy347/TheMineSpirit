# The Mine Spirit — план работ

Примерный план в виде чеклиста, без деталей. Блок, который берут в работу, выносится в подробный чеклист
`tasks/<NN>-<имя>.md` и здесь сокращается до ссылки; после выполнения и ревью чеклист удаляется, строка
отсюда вычищается (цикл — docs/LEAD-AGENT.md). Отмечать готовым только после проверки тестами и ревью.

## Тактическое и стратегическое поведение (карта решений, без деталей)

Слои: политики (рефлекс, каждый тик) → тактика (бой / отход / режим) → стратегия (цели и планы) → простой.
Приоритет: политики > тактика > стратегия; верхний слой может прервать действие нижнего. Поведение разумное и так-
тическое, логика описывается высокоуровнево и декларативно («ситуация → действие/режим»), а не императивно.

## Специализации, роли и социальность (стандартный Minecraft, без модов)

Специализация = данные (профиль): набор скриптов + рабочие точки + предпочтения + роль. Переключается стратегией,
исполняется конкретными действиями. Тактика и политики общие для всех профессий, профессия их не отменяет.

### Фермерство (земледелие)
- [ ] посевы: арбуз/тыква; тростник/бамбук/кактус/сладкие ягоды/какао (пшеница, морковь, картофель, свёкла — сделаны)
- [ ] цикл: компост (вспахать → посадить → вырастить → собрать → костная мука — сделано)
- [ ] хранение и распределение урожая

### Животноводство
- [ ] разведение и кормление (пшеница/семена/морковь), рост детёнышей
- [ ] стрижка овец, доение, сбор яиц/перьев, шерсть
- [ ] загон и безопасность стада; контроль популяции: кормить и забивать (железный меч и выше, не руками)
- [ ] пчёлы: ульи, соты, мёд

### Лесничество (древодел)
- [ ] рубка по цели; костная мука для роста (рубка по виду и посадка саженцев — сделаны)
- [ ] гигантские деревья 2×2; обновление участка шире пересадки на месте ствола
- [ ] переработка: доски, палки, уголь (печь)

### Горное дело (рудокоп)
- [ ] безопасная шахта: лестницы/штольни, освещение, крепь

### Кузнечество (металлургия и ремесло)
- [ ] наковальня, стол кузнеца (печь и плавка — сделаны)
- [ ] инструменты, броня, оружие; ремонт и комбинирование
- [ ] заготовки (дерево/камень/металл), склад материалов

### Алхимия (зельеварение)
- [ ] варочная стойка, топливо (пламень), котёл
- [ ] сбор ингредиентов (травы, незер), варка, раздача зелий
- [ ] лечение и поддержка союзников

### Рыболовство
- [ ] удочка (удача/приманка), ловля рыбы и «мусора»
- [ ] обработка улова (печь/коптильня); ведро с рыбой
- [ ] рабочая точка у воды, маршруты; автоматизация: рыбалка как постоянное занятие

### Строительство (зодчество)
- [ ] база, стены, крыша, освещение; склады и маршруты
- [ ] фермы/загоны/доки по чертежу; ремонт построек

### Кулинария
- [ ] печь, костёр, коптильня; готовка еды; распределение еды

### Разведка и картография
- [ ] исследование, карты, метки ресурсов/опасностей, разведрейды

### Социальность: роли, семья, иерархия
- [ ] роли: лидер, рабочий, защитник, разведчик, лекарь, логист/склад
- [ ] профессия привязана к рабочей точке (грядка/наковальня/вода/улей/стол)
- [ ] поселение: не больше 12 духов, в итоге несколько пар
- [ ] спавн: игрок создаёт взрослых и сам назначает пол
- [ ] рождение: пол назначает алгоритм (баланс пар)
- [ ] семья: муж, жена, дети — других отношений нет; между собой не конфликтуем
- [ ] связь муж-жена; взрослые одиночки женятся (по интервалу); разводов нет
- [ ] матчмейкинг/баланс пар следит алгоритм
- [ ] у пары одновременно не больше 1 ребёнка; родители заводят детей повторно, пока не достигнут лимит
- [ ] интервалы: взросление, женитьба, повторное заведение детей (данные, тюнятся)
- [ ] всё общее: дом, склад, ресурсы; взаимозащита и помощь
- [ ] иерархия и команды лидера; приоритеты задач
- [ ] игрок — союзник (торговли с игроком нет; с жителями — да); команды игрока приоритетнее всех целей
- [ ] настроение (простые коэффициенты), без внутренних конфликтов

### Дети
- [ ] растут по интервалам до взрослых
- [ ] посильная работа: собирают овощи, таскают брёвна в сундуки, собирают лут
- [ ] остальное время бегают и играют (в т.ч. «играют мечами»)
- [ ] воевать могут редко; после первого удара убегают
- [ ] всё прочее (профессии, бой, крафт) — только взрослые
- [ ] LLM не меняет поведение детей (детские цели не выдаются)

### Экономика и логистика (базово)
- [ ] склад: сортировка, поиск, учёт
- [ ] доставка ресурсов между точками и духами; спрос/предложение по профессиям

### Торговля с жителями
- [ ] торговля со всеми: жители деревень и странствующие торговцы
- [ ] продаём только избыток (surplus), не трогая дефицит и нужное себе
- [ ] продаём только то, что умеем производить сами (бумага, еда и т.п.)
- [ ] зачарованные предметы не продаём
- [ ] порог избытка — таблица на душу населения, в стаках: норма × число духов
- [ ] в «душу населения» входят и дети
- [ ] предварительно: 1 стак на бота для всех продаваемых предметов (позже уточнить)
- [ ] изумруды не трогаем: складываем, но не тратим — распоряжается игрок
- [ ] «умеем делать» и «избыток» — из учёта склада и профессий (данные)

### Общее для всех профессий
- [ ] профиль профессии — данные, переключается стратегией
- [ ] все специализации доступны всем духам сразу (без прокачки и «новичков»)
- [ ] тактика/политики общие; угроза прерывает работу, затем работа возобновляется
- [ ] рабочая точка и маршруты; возобновление после угрозы и ночного режима
- [ ] инвентарь всегда в порядке: при каждом обращении сортировать вещи в сундуках

## Инвентарь, ценности и поход

- [ ] выпавшие предметы подбираем инстинктивно
- [ ] на базе разгружаем инвентарь в сундуки, кроме базового набора (без фанатизма)
- [ ] по команде «идём в поход» готовимся: берём нужное без фанатизма
- [ ] при переполнении: подбираем самое дорогое, дешёвое выбрасываем
- [ ] «дорого/дёшево» осмысленно и контекстно: нужный ресурс (напр. лодка для реки) не выбрасываем
- [ ] оценка ценности — данные (таблица ценностей), а не хардкод

## Распределение работ и сбор в поселении

- [ ] каждый взрослый в единицу времени занят одной работой
- [ ] алгоритм заранее распределяет работы, чтобы все не бежали за одним лутом
- [ ] кто выполняет работу — тот и собирает её лут
- [ ] claim/lease: при боевом прерывании работа на паузе с резервом; затянулось — освободить и перераспределить (тайм-аут тюним)
- [ ] остальные взрослые: помогают (локальная привязка) или уходят на более приоритетную работу
- [ ] локальная привязка: дух привязан к рабочей точке / напарнику / лидеру
- [ ] дети чаще помогают своим родителям (привязка к родителям)
- [ ] примеры занятий: грядки (с детьми), рыбалка (с детьми), рубка леса (дети таскают брёвна), контроль животных
- [ ] дух сам собирает выпавший лут; взрослые тоже собирают

## Порталы и гибель игрока

- [ ] портал проходим только при следовании за игроком
- [ ] гибель игрока касается духов, привязанных к походу с игроком
- [ ] они защищают место гибели (радиус 20–50), строят укрытие из подручного и баррикадируются
- [ ] укрытие маленькое (5–10 блоков); один строит — другие защищают; оценка обстановки
- [ ] если место гибели ближе 100 блоков к базе — просто возвращаются на базу
- [ ] далее ждём инструкцию LLM: идти обратно или дождаться игрока

## Оборона базы и координация

- [ ] умная тактика обороны: каждый взрослый защищает свою область
- [ ] защитники координируются и подменяют друг друга (ротация)
- [ ] работают как слаженная команда; прикрывают друг друга
- [ ] стройка в бою только с прикрытием: один строит — остальные защищают

## Управление и ИИ (команды и стратегия)

- [ ] команды принимают и игрок, и духи: текст уходит в LLM, LLM трактует и выбирает стратегию
- [ ] команды игрока приоритетнее всех прочих целей
- [ ] LLM вызывает REST раз в несколько минут и формирует глобальные задачи/цели для каждого духа
- [ ] тактика детерминированная; LLM — только стратегия
- [ ] событийный ре-план: критичное (напр. нападение) решает тактика немедленно, без ожидания LLM; в остальном ждём LLM
