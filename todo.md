## Тактическое и стратегическое поведение (карта решений, без деталей)

**Принцип (решение владельца 13.10): тактический интеллект ЕДИНЫЙ для всех духов, а не у каждого свой.** Он видит
состояние всех: кто где, кто чем занят, кто как защищается, кому нужна помощь, — и выдаёт конкретное задание
конкретному духу. Сейчас `TacticsService` создаётся у каждого `SpiritEntity` — это нужно свести к общему координатору.

**Терминология (владелец 13.10, подробно — tasks/32-tactical-intelligence.md):** стратегический интеллект — настоящий ИИ, один на всех
(opencode/Sonnet по REST раз в 1–5 мин: смотрит, кто чем занят, корректирует, ставит задания в очередь; docs/STRATEGIST.md); тактический
интеллект — детерминированный алгоритм, один на всех: очередь стратегического интеллекта первой, иначе сам считает востребованность
деятельностей и раздаёт их духам, с вытеснением менее важного; деятельность — вид занятия с общим интерфейсом (у
детей свой список); оценка сил врагов и духов решает, кого в бой, кому бежать/за оружием/лечиться.

- [ ] Стратегический интеллект — один на всех (docs/STRATEGIST.md): переделать `agents/strategist` с «вызов модели на каждого
      простаивающего духа» на «одно наблюдение всего поселения → одно решение»: корректировки и очередь заданий

      и очередь заданий духа — в контракт API.
Слои: политики (рефлекс, каждый тик) → тактика (бой / отход / режим) → стратегия (цели и планы) → простой.
Приоритет: политики > тактика > стратегия; верхний слой может прервать действие нижнего. Поведение разумное и так-
тическое, логика описывается высокоуровнево и декларативно («ситуация → действие/режим»), а не императивно.

## Комментирование и диалоги (решение владельца 14.10)

Потребность в репликах и отдельный вид деятельности «диалог». Перевод реплик в аудио — отдельным решением, требует
предварительного согласования с пользователем.

### Комментирование действий
Отложено (владелец 15.10): к репликам и диалогам вернёмся позже. Генерация текста — у стратегического интеллекта заранее
(запас фраз под ситуации, мод выбирает из запаса), а не в момент события.

- [ ] Потребность комментировать: бот может произнести фразу, когда чем-то занят (рубит дерево, сражается) или когда
      мимо проходит игрок; текст фразы заранее готовит стратегический интеллект.
- [ ] Вероятность реплики зависит от слышимости игрока: выше, если игрок рядом; нулевая, если игрок не слышит бота.
- [ ] Реплики не мешают основной деятельности и не спамят: интервалы/лимиты — данные, тюнятся.
- [ ] Перевод текста в аудио (озвучка) — отложено до согласования с пользователем.

### Вид деятельности «диалог»
- [ ] Отдельная деятельность наравне с рыбалкой, фермерством и прочими.
- [ ] Не выбирается тактическим интеллектом: поставить её может только стратегический интеллект, заранее сгенерировав диалоги.
- [ ] Участвуют минимум два бота; верхнего предела нет — число участников решает стратегический интеллект и сразу готовит диалоги для всех.
- [ ] Боты подходят друг к другу и смотрят друг на друга; если ботов несколько — все смотрят на того, кто сейчас говорит.
- [ ] Говорящий смотрит на любого из своих собеседников и активно двигает руками во время своей реплики.

- [ ] Приручение волков: кормление костью; приручённый волк следует за духом и участвует в обороне.
- [ ] Приручение оцелотов: кормление сырой рыбой (треска/лосось); приручённый оцелот становится кошкой-питомцем.
- [ ] Размножение приручённых: волкам — мясо, оцелотам — сырая рыба; учёт детёнышей, рост и наследование приручённости.
- [ ] Кормление питомцев в общем цикле животноводства (кому поручено, из каких запасов) — данные.
- [ ] Лимит поголовья: на каждый вид не больше половины числа духов в поселении с округлением вниз
      (10 духов → максимум 5 волков и 5 оцелотов); при достижении лимита размножение не запускается.
- [ ] Уточнение (владелец 15.10): у каждого вида свой лимит, всё настраивается данными; в число духов входят и дети,
      и взрослые; свои настраиваемые лимиты есть и у прочих животных (стада, лошади).

## Постройки и застройка поселения (решение владельца 14.10)

Постройки — только готовые наборы (пресеты), заранее прочитанные в моде. Пользователь ставит базовую точку, дальше
стратегический ИИ раскладывает готовые конструкции по территории. Размеры уточняются позже; ориентир — просторно, с запасом.

- [ ] Библиотека готовых построек (~100 вариантов), прочитанных заранее в моде: домики для семьи из 3 человек, склады,
      фермы, загоны для животных, минибазы (похожие на казармы), заборы, ворота, башни для лучников, укреплённые стены и т.д.
- [ ] Базовую точку ставит пользователь; стратегический интеллект из готовых конструкций составляет планировку — расположение домиков,
      дорог, тропинок, насаждений цветов, ферм.
- [ ] Обязательно оградить всю территорию укреплённой стеной (на стену можно забраться), с воротами и малыми воротами в стене.
- [ ] Приоритет застройки по порядку: сначала ограждение всей территории простым забором из палок, затем освещение всей
      территории факелами, затем простой дом по середине из камня.
- [ ] По мере развития: простой забор из палок → укреплённая каменная стена; строим дома для всех; первоначальный дом
      сносим и строим из него дом для игрока; простые факелы заменяем на красивые светильники.

## Типы строений и этапы развития поселения (решение владельца 14.10)

### Типы строений
- [ ] Жильё: хижина → дом семьи (на 3) → дом игрока; общежитие/минибаза (казарма).
- [ ] Склады: общий склад (расширяемый), склады материалов/еды/ценностей, амбар.
- [ ] Фермы и еда: пашни (пшеница, морковь, картофель, свёкла), сад, лесопилка, загоны (коровы, овцы, свиньи, куры),
      пчельник, рыбный док, колодец/акведук, кухня-пекарня, столовая.
- [ ] Ремёсла: мастерская-верстачная, кузница (печи, наковальня, точило), плавильня, ткацкая, алхимическая лаборатория,
      чаровальня (см. выше).
- [ ] Оборона: палисад → частокол → каменная стена с бойницами; ворота и малые ворота; башни лучников; сторожевые
      вышки; ров + мост; казармы.
- [ ] Инфраструктура: дороги и улицы, тропинки, освещение (факелы → светильники), вход в шахту, карьер/каменоломня,
      лесосека, мосты, дренаж.
- [ ] Социальное: площадь, ратуша (центр управления), таверна, лазарет, библиотека, тренировочный двор, торговый пост/лавка.
- [ ] Питомцы: питомник волков/оцелотов, конюшня.
- [ ] Дальние: аутпосты-минибазы, маяк, причал.

### Этапы развития
- [ ] Этап 0 «Лагерь выживания»: шалаши/укрытия, костёр, пара сундуков; палисад из палок; факелы по периметру; шахта-нора.
- [ ] Этап 1 «Деревянная деревня»: каркасные деревянные хижины для семей, деревянный дом-склад, простые фермы и загоны,
      колодец; палисад → деревянный частокол; тропинки из гравия; площадь расширяется с запасом.
- [ ] Этап 2 «Каменное поселение»: дома на камень/булыжник, первый дом → дом игрока; каменная стена с бойницами и
      воротами + башни лучников; кузница, пекарня; склады расширяются; факелы → фонари.
- [ ] Этап 3 «Укреплённый город»: сплошная каменная/кирпичная стена, ров и мост, укреплённые ворота, башни; казармы,
      лазарет, таверна; площадь-ратуша; мастерские, большой склад, дороги, дренаж.
- [ ] Этап 4 «Развитое общество»: обтёсанные каменные дома с улучшениями, декоративные светильники, красивые улицы и
      насаждения; кварталы (жилой, ремесленный, торговый); торговый пост, библиотека; аутпосты-минибазы, маяк, причал.

### Два измерения развития
- [ ] Качественное: материал (палки → дерево → камень → кирпич/обтёсанный камень), надёжность (шалаш → дом;
      палисад → стена), декор (факелы → светильники; тропа → улицы), специализация зданий.
- [ ] Количественное: число домов растёт по населению (дом на семью из 3 + общежития), склады расширяются при заполнении
      меньше 20% свободного места; новая постройка появляется по потребности; планировка просторная, с запасом.

## Скоростное строительство укрытий (решение владельца 14.10)

Общая методика быстрого укрытия: применяем и для отлова животных, и для защиты от мобов в критичный момент вдали от базы.

- [ ] Два шаблона (владелец 15.10), размеры примерные, числа — данные:
      - боевое укрытие для группы — около 4×4, стены высотой 2, с крышей (без крыши пауки залезают, скелеты стреляют
        поверх стен); один дух строит, остальные защищают (чеклист 34); сюда же «укрытие при гибели игрока»;
      - быстрое укрытие для одного духа или животного — площадка 2×2 или 3×3, высотой в два блока, с крышей и дверью.
- [ ] Когда приступим — продумать максимально быстрый и эффективный алгоритм строительства (порядок установки
      блоков, заход внутрь, установка двери) — отдельная проработка.
- [ ] Для животных после установки двери дополнительно фиксируем дверь блоком снаружи (зомби могут ломать двери).
