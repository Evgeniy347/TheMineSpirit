# Механизмы временной правки мира: объявленный выход и тест прерывания.
# Формат строки: writer | script | exit | test | reason
# writer — файл production-кода с вызовом .markTemporary( (путь от пакета neoforge).
# script — класс-владелец правки, который запускается скриптом.
# exit — что остаётся при cancel/suspend/смерти и почему это видно графу.
# test — существующий тест прерывания Class.method; имя метода содержит Interrupt.
# Исключения формата exception | path | reason — writer без теста, только с причиной.
# Все временные правки этапа 2 переведены на аренду: writer без markTemporary здесь не значится.
