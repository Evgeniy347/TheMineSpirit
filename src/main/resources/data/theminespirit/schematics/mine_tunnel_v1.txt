# Стенки: каждая клетка рядом с проходом (кроме торцов хода по длине) — @floor на всю высоту: дух и игрок не

# 'T'/'U' — необязательный настенный факел в клетке прохода у стенки (мягкая клетка): в начале факелов нет, без них ход строится
# и аудит не падает; когда появится уголь, дух доставит факелы по этим клеткам.
#
# repeat: сегмент хода по умолчанию один; длину задаёт стройка числом сегментов (times), шаг — [0,0,20].
#
# Жилы: ход может пересечь жилу — руду из клеток хода забрать, не оставляя её в полу/стенах прохода.

# не должна затапливать проход; пол ставится до вскрытия источника, а вода/лава отводится или
# перекрывается. Это отдельная проверка строителя, схема жидкостей не содержит.
