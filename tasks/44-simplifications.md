# Чеклист 44. Упрощения механик (согласовано владельцем 18.10, Telegram #3346)

Правило (владелец 18.10): дух может «читерить» в досягаемости и подборе, если это убирает класс багов; числа — данными;
действие всегда строго ограничено целевыми блоками/предметами/существами (чужое не трогает). Каждое такое упрощение
описывается и ЯВНО согласуется с владельцем до реализации. Если исполнители застревают на механике — это повод
предложить владельцу упрощение (главный агент сам следит и спрашивает).

Уже согласованы и сделаны/в работе: рубка с места (всё дерево, только выбранное), стройка с досягаемостью 3/15 без лесов.

## Пункты (все согласованы 18.10)

1. **Подбор «магнитом»**: всё выпавшее в радиусе R (данными, ~5) от духа само попадает в инвентарь духа (если есть
   место); только свободные предметы-дропы (не рамки, не предметы игрока, брошенные им недавно — защита данными).
2. **Контейнеры и станции в радиусе**: сундук/верстак/печь/наковальня и т.п. — работа с блоком в досягаемости
   3 по горизонтали / 15 вверх (`SpiritReach`), без прямой видимости, без точного подхода.
3. **Добыча с места**: встал у жилы — ломает всю жилу (только руду этой связной жилы, предел числа данными) с места;
   копка области — с нескольких стоянок по правилу досягаемости; без столбов и спусков ради досягаемости.
4. **Ловля животных**: поводок (ваниль) или приманка (животное с кормом в руке духа идёт за ним) в загон;
   «кольцо» из блоков вокруг животного убрать.
5. **Отход без стройки**: при отходе дух не строит столбы/баррикады; только уходит к дому/союзнику/игроку/воде.
6. **Застревание**: не сдвинулся N секунд (данными) к цели — телепорт на 1–3 блока к цели по свободной клетке
   (или в последнюю пройденную точку пути); без сложной логики повторов.
7. **Переправа через воду**: только вплавь (или по дну); мост (`bridge`) из переправы убрать.
8. **Рыбалка**: «рыбачит» у воды N секунд (данными) → улов по ванильной таблице лута, без поплавка.
9. **Ферма**: вспашка/посадка/сбор с нескольких стоянок по правилу досягаемости, без хождения по каждой грядке.

## Порядок

Каждый пункт — отдельная небольшая задача; тесты: JUnit на правило (числа из данных, ограничение целями) + GameTest
сценария; старые тесты переделать по существу (не ослабляя). Удаляемая сложная логика удаляется вместе с её
тестами только если механика действительно убрана владельцем (пункты 4, 5, 7, 8).
