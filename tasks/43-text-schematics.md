Статус (19.10): выполнено в ветке `opus/work`, ждёт приёмки; открыт флек `crater_dirtgate_fillsflat`.

Источник правды для всех построек — текстовый файл слоёв с легендой (YAML-подобный), один на постройку/уровень.
Мод читает его напрямую; отдельного JSON со списком координат нет. Импорт из ванильного Structure Block (.nbt) →
текст — вспомогательный путь (владелец строит в креативе, конвертер выдаёт текст).

## Формат (черновик)

```
# family_house — дом семьи на 3
size: 7x5x7            # Ш × В × Д
entrance: front        # сторона входа; front = первая строка каждого слоя
legend:
  '#': oak_planks
  '=': oak_log
  'P': glass_pane
  'D': oak_door        # двухчастный — верхняя половина ставится автоматически
  'B': white_bed[head=back]
  'T': wall_torch[facing=auto]
  '.': air             # клетка обязана быть пустой
  ' ': any             # клетку не трогаем
exemptions:            # исключения сторожей — только с причиной
  - rule: window
    reason: "склад без окон по замыслу"
layers:
  - y0 floor: |
      #######
  - y1: |
      =##D##=
```

## Конвертор (скрипт + тот же код в моде)

1. Ресурсы: блоки и число предметов; опционально разворот до сырья (доски → брёвна).
2. Раскладка: порядок постановки снизу вверх с учётом опоры; координаты и состояния для 4 поворотов.
3. Сторожа: дверь с проходом к земле, окна, крыша без дыр, замкнутые стены, свет, опора, сундук открывается;
   исключения — в файле с причиной.
4. Просмотр: срезы по слоям в консоли (позже — изометрия).
