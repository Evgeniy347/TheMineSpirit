# Чеклист 49. Шахта по схеме (владелец 22.10)

Статус (23.10): выполнено в ветке `opus/mine-builder`, ждёт приёмки; вопросы — `QUESTIONS-49.md`.

Схемы владельца — `schematics/mine_descent_v1.txt` (спуск 1×3, шаг вперёд — на блок ниже) и `mine_tunnel_v1.txt`
(ход-крест 2×3×20 с ветками 2×3×2); описание замысла — в комментариях самих файлов. Шахта строится по схеме, с учётом
правил добычи руды. Закрывает чеклист 48 п.4 (выход из шахты, утопление) и п.21 (булыжник только в шахте).

## Формат и сторожа (часть A)

1. [x] Класс блоков в легенде: `'#': @floor` — любой твёрдый дешёвый блок (камень, булыжник, земля, глубинный
   сланец, туф, андезит/диорит/гранит…). Стоит такой — не трогаем; воздух/жидкость/руда — ставим булыжник. Гравий и
   песок — только если под ними опора, иначе замена. В спуск добавить пол `@floor` под каждой ступенью; в ходе
   заменить `'#': stone` на `@floor`. Аудит сверяет клетку `@floor` по классу, а не по точному блоку.
2. [x] Повтор сегмента: в шапке `repeat: {step: [dx, dy, dz], until: "y=50"}` (или число сегментов) — файл описывает
   один сегмент, строитель, план стройки (`BuildPlanner`, снапшоты) и аудит разворачивают его до условия. Спуск — шаг
   [1,-1,0] до y=50; ход — повтор по длине (сколько сегментов — параметр стройки).
3. [x] Сторожа для подземных построек — свой набор для типа `underground` (схемы переводятся на него) вместо
   исключений: под каждой воздушной колонкой — пол; высота прохода ≥ 3; шаг вверх/вниз по ходу ≤ 1 блок (дух выходит
   наверх пешком — это и есть фикс выхода из шахты); вход — верхняя клетка спуска; свет — см. п.4. Исключения
   `entrance`/`entrance_step`/`light` из схем убрать. Проверка — `bash scripts/schematic.sh check`.
4. [x] Свет: факелы в схеме — **необязательные** клетки (мягкие, как `~`): в начале факелов нет (нужен уголь), спуск и
   ход строятся без них; когда факелы появились — дух их доставляет по схеме (шаг не реже чем через 6 блоков хода,
   на стене). Аудит не валит постройку без необязательных факелов. Правило «без факела не начинать постройку»
   (чеклист 48 п.8) на подземные постройки не распространяется.
5. [x] Каталог: `mine_descent`, `mine_tunnel` в `buildings.json`/`presets.json`, снапшоты планов, тесты каталога
   (`DemoBuildingsTests`, `PresetLibraryTests`) зелёные; `/spirit demo mine_descent`, `/spirit demo mine_tunnel`.

## Строитель шахты (часть B)

6. [x] Стройка по схеме: клетки `.` выламываются, пол `@floor` ставится до шага вперёд; булыжник добывается только
   так — в шахте (чеклист 48 п.21: задача «добудь булыжник» — только после полного набора деревянных инструментов и
   после входа в шахту и самой шахты).
7. [x] Руда в клетках хода: обычную — добыть подходящей киркой. Алмазы/лазурит (и другие руды «на удачу» — список
   обосновать) без кирки с Удачей: Шёлковое касание, если есть, — добыть блок целиком на склад; иначе — оставить
   блок, запомнить позицию в памяти поселения и **прорубить обход рядом** (справа/слева/сверху/снизу — любой
   удобный), чтобы дух не застревал. Тесты на каждый случай.
8. [x] Жидкости: ход вскрывает источник воды/лавы в стене, полу или потолке — проход не затапливается: пол ставится
   до вскрытия, источник перекрывается булыжником. Не копать в воду; при малом запасе воздуха — аварийный подъём
   (чеклист 48 п.4, INC-19: дух утонул).
9. [x] Выход наверх: из любой точки шахты дух выходит на поверхность пешком по ступеням спуска; GameTest «дух у дна
   спуска на y=50 выходит наверх» и «дух в ходе с водой не тонет».
