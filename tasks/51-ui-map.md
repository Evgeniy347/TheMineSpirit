# Чеклист 51. Экран поселения: доска, план города, план шахты (владелец 22.10)

Решение: свой экран на ванильных средствах (Screen + GuiGraphics, вкладки в стиле книги/достижений), без новых
зависимостей; интеграция с JourneyMap — позже, необязательным слоем.

1. [x] Экран по клавише **J** (переназначаемая), три вкладки: доска задач (позже), план города, план шахты.
   Сделано: клавиша и экран с вкладкой доски (`neoforge/client/BoardScreen`); вкладки карт — с п. 2–3.
2. [ ] План города: карта **любой видимой (загруженной) области** — цвет MapColor верхнего блока, тайлы 16×16 от
   сервера; слои: граница территории, участки (рамка + подпись), духи. Подсказка с названием участка при наведении.
3. [ ] План шахты: срез на выбранной высоте y (переключение), проходы/пол/оставленная руда/вода и лава.
4. [ ] Колесо — масштаб, зажатая ЛКМ — сдвиг.
5. [x] Данные — только при открытии экрана (без живого обновления); видят **все игроки**.
6. [ ] Сборка тайлов и слоёв — чистые функции в `core` с тестами; сетевой канал — через ModProtocol.
   Для доски сделано: `core/ui` (снимок, порядок, фильтры) и канал `BoardViewChannel`; тайлы карт — с п. 2–3.
7. [x] Вкладка «Доска задач»: плитки (завершённые → активные → доступные → недоступные), текст на ru/en,
   приоритет, исполнитель или «…», фильтры по статусу и исполнителю, прокрутка колесом.
