# Чеклист 51. Экран поселения: доска, план города, план шахты (владелец 22.10)

Решение: свой экран на ванильных средствах (Screen + GuiGraphics, вкладки в стиле книги/достижений), без новых
зависимостей; интеграция с JourneyMap — позже, необязательным слоем.

1. [x] Экран по клавише **J** (переназначаемая), три вкладки: доска задач, план города, план шахты.
   Первая реализация — **только доска задач**, одна вкладка, общий список плитками (п.7); карты — следом.
2. [ ] План города: карта **любой видимой (загруженной) области** — цвет MapColor верхнего блока, тайлы 16×16 от
   сервера; слои: граница территории, участки (рамка + подпись), духи. Подсказка с названием участка при наведении.
3. [ ] План шахты: срез на выбранной высоте y (переключение), проходы/пол/оставленная руда/вода и лава.
4. [ ] Колесо — масштаб, зажатая ЛКМ — сдвиг.
5. [x] Данные — только при открытии экрана (без живого обновления); видят **все игроки**.
6. [ ] Сборка тайлов и слоёв — чистые функции в `core` с тестами; сетевой канал — через ModProtocol.
7. [x] Доска задач (первая реализация, владелец 23.10): общий список плитками, порядок групп:
   1) завершённые — по времени; 2) активные; 3) доступные (есть инструменты и ресурсы) — по приоритету;
   4) недоступные (не хватает ресурсов/инструментов) — по приоритету. Плитка: текст задачи, приоритет,
   исполнитель (кто делает/сделал) или «…», если никто не брался. Сверху фильтры: по статусу, по исполнителю.
   Данные — снимок доски при открытии экрана (как `/v1/board`), сортировка и фильтры — чистые функции в `core`.
   Доработано 23.10: окно и плитки растягиваются по размеру экрана (шрифт не меняется); четыре колонки —
   завершённые, выполняющиеся, доступные к выполнению, невозможно приступить; у каждой колонки своя прокрутка
   колесом под курсором; у плиток ожидающих заданий причина конкретна (свободный дух, дух по имени, ресурс X×N,
   инструмент X×N, задание-зависимость, блокировка после провалов), раскладка и причины — чистые функции
   `core/ui` (`BoardColumns`, `BoardWaitReasons`), тексты в lang под сторожем `BoardLangTests`.
