# Чеклист 51. Экран поселения: доска, план города, план шахты (владелец 22.10)

Решение: свой экран на ванильных средствах (Screen + GuiGraphics, вкладки в стиле книги/достижений), без новых
зависимостей; интеграция с JourneyMap — позже, необязательным слоем.

1. [x] Экран по клавише **J** (переназначаемая), три вкладки: доска задач, план города, план шахты.
   Первая реализация — **только доска задач**, одна вкладка, общий список плитками (п.7); карты — следом.
2. [ ] План города: карта **любой видимой (загруженной) области** — цвет MapColor верхнего блока, тайлы 16×16 от
   сервера; слои: граница территории, участки (рамка + подпись), духи. Подсказка с названием участка при наведении.
3. [x] План шахты: срез на выбранной высоте y (переключение), проходы/пол/оставленная руда/вода и лава.
   Первая реализация (владелец 26.10, «быстро, простые прямоугольники»): вкладка «План» рядом с доской, карта из
   `TownSnapshot` — участки построек прямоугольниками с подписью, подсказка: название и % готовности, у повреждённой —
   % до восстановления; улицы и тропинки — прямоугольники; контур плана и ограда этапа — линии с калитками.
   Раскладка — `core/ui` (`TownMapView`, `MapViewport`, `MapPaint`, `MapHit`, `MapHint`, `ScreenTabs`); скрины
   Java2D той же раскладкой — `TownMapPngTests` → `build/map-screens/`. Цвет MapColor — не сделан.
   Метки духов и игроков (26.10): имя, позиция, занятие духа из доски; разные цвета, подпись имени, подсказка при
   наведении; обновление раз в секунду лёгким запросом. Раскладка и попадание — `MapMarkers`.
   Реализация среза (26.10): вкладка «Шахта»; снимок через `MineMapChannel` при открытии вкладки и смене высоты.
   Срез на y — `MineGeometry`/`MineSnapshot` (проходы, пол, спуск, руда, вода, лава); постройки «Спуск» и
   «Шахтный ход» прямоугольниками с % готовности при наведении; духи и игроки в шахте — `TownMarkers` с фильтром
   по высоте. Колесо — масштаб, Shift+колесо и ↑/↓ — высота, ЛКМ — сдвиг. Раскладка — `MinePaint`, попадание —
   `MineHit`; скрины Java2D — `MineMapPngTests` → `build/map-screens/mine-*.png`.
4. [x] Колесо — масштаб, зажатая ЛКМ — сдвиг.
5. [x] Данные — только при открытии экрана (без живого обновления); видят **все игроки**.
6. [x] Сборка тайлов и слоёв — чистые функции `core/ui` (`TerrainColor`, `TerrainTile`, `TerrainRaster`, `MapPaint`);
   тайлы 16×16 с цветом MapColor верхнего блока, кеш по чанку на сервере, канал — `TownMapChannel`.
7. [x] Доска задач (первая реализация, владелец 23.10): общий список плитками, порядок групп:
   1) завершённые — по времени; 2) активные; 3) доступные (есть инструменты и ресурсы) — по приоритету.
   Плитка: текст задачи, приоритет, исполнитель (кто делает/сделал) или «…», если никто не брался.
   Сверху фильтры: по статусу, по исполнителю. Данные — снимок доски при открытии экрана (как `/v1/board`),
   сортировка и фильтры — чистые функции в `core`.
   Доработано 23.10: окно и плитки растягиваются по размеру экрана (шрифт не меняется); три колонки —
   завершённые, выполняющиеся, доступные к выполнению; у каждой колонки своя прокрутка колесом под курсором;
   у плиток ожидающих заданий причина конкретна (свободный дух, дух по имени, ресурс X×N, инструмент X×N,
   задание-зависимость, блокировка после провалов), раскладка и причины — чистые функции `core/ui`
   (`BoardColumns`, `BoardWaitReasons`), тексты в lang под сторожем `BoardLangTests`.
   Доработано 24.10: заголовки колонок на тёмной подложке с тенью; задания, которые не удалось завершить
   (не хватает ресурсов, провалены, заблокированы, ждут зависимость), стоят в завершённых с красной подписью
   «не удалось завершить» и причиной в подсказке.
8. [x] Экран J: на плитке задания — когда дух начал, когда закончил и сколько затрачено (игровое время/реальное); данные из журнала доски (ASSIGNED/DONE/FAILED), раскладка — чистые функции core/ui с тестами (владелец 25.10, исполнитель deepseek).
