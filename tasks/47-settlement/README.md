## Замысел в двух абзацах

**Библиотека:** 38 семей построек, ≈110 уровней. Семья — одно назначение на одном участке; участок сразу
резервируется под высший уровень, улучшение идёт на месте с дверью-якорем (как уже сделан `upgrade` загона).
У главных построек 4 уровня (дом семьи, дом игрока, склад, стена, ворота, улицы, светильники), у большинства 3,
у второстепенных 2. Уровень 1 — скромно и аккуратно (одна комната, свес, ставни, клумба), уровень 4 — заметно
богато (зал на два этажа с галереей, арка, несколько входов, балкон, вальмовая крыша). Материалы — по этапу
поселения: дерево на булыжнике → камень с фахверком → каменный кирпич → кирпич и гладкий камень.

**План поселения:** детерминированный планировщик в моде кладёт шаблон «крест с кольцом» центром в базовую
точку: площадь, парадная ось «главные ворота → площадь → дом игрока», поперечная главная улица, кварталы
(жилой, общественный, хозяйственный, ремесленный у шахты, аграрный у ворот), кольцевая улица вдоль стены.
Стратег правит план через REST с проверкой. Ограждение — сегменты по 8 блоков: забор → частокол → каменная
стена с помостом → крепостная с рвом. Каждая постройка и сегмент — запись реестра: по нему тактика выбирает
следующую стройку (нужды из данных) и чинит повреждения по схеме, не трогая блоков игрока.

## Что уже есть и переиспользуется

Текстовые схемы и сторожа `SchematicRules`; `PresetLibrary` с уровнями (`requires`, `planned`); якорь по двери и
повороты (`DemoPlacement`, `BuildRotation`); стройка с места (`ReachPlanner`, `SchematicSite`); `BuildSquad`;
доска заданий с кейсами `BUILD_*`, `REPAIR_BUILDING`, `REPAIR_FENCE`, `RELOCATE_BUILDING`, `LIGHTING`,
`FILL_CRATER` и гейтом по ресурсам; `FirstStepsPlan`; скрипты `light_area`, `build_fence`, `fill`, `chop_target`.
Новое — пакет `core/settlement` (format.md). Нынешние 16 схем остаются: часть становится уровнями семей
(`storage_v1..v4`, `pen_*`, `enchant_room_v*`, `well`, `torch_post`, `mine_entrance_v1`), `family_house` и
`stone_house` заменяются уровнями 1 новых семей.
