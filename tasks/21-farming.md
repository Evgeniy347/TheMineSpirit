## Что должно получиться

Дух ухаживает за грядкой четырьмя скриптами; радиус считается от текущей позиции духа (на место стратег приводит `goto`):

- `till(radius, count)` — вспахать до `count` ближайших клеток `dirt` / `grass_block` / `dirt_path`, над которыми воздух или сорная
  трава (замещаемое растение: его дух сначала срубает рукой), **и до которых доходит вода** (ваниль: вода в пределах 4 блоков по
  горизонтали на уровне земли или на блок выше; иначе земля пересохнет и вернётся в землю). Нужна мотыга любого сорта в
  инвентаре; износ мотыги — как у игрока.
- `plant_crop(crop, radius, count)` — посадить `crop` (`wheat | carrot | potato | beetroot`, обязателен) на пустую вспаханную
  землю с воздухом сверху, `count` клеток; посадочный предмет — из инвентаря (`wheat_seeds`, `carrot`, `potato`, `beetroot_seeds`).
- `harvest_crop(crop, radius, replant)` — собрать **всё зрелое** в радиусе (`crop` = `any` по умолчанию). Зрелость — по возрасту
  блока: `age == maxAge` (пшеница, морковь, картофель 0..7; свёкла 0..3). Недозрелое **не трогается**. При `replant = true`
  (умолчание) каждая сломанная клетка тут же засаживается заново тем же видом: это и есть самоподдерживающаяся грядка
  (собрал → подобрал дроп → посадил). Семена берутся из урожая и инвентаря; не хватило — клетка остаётся пустой и считается.
- `bone_meal(crop, radius, count)` — потратить до `count` единиц костной муки на ближайшие **недозрелые** посевы; зрелые муку
  не тратят; муки нет — отказ до начала.
- Дух не топчет грядку (число клеток `farmland` до и после работы одинаково), не встаёт в клетку, которую обрабатывает, не
  стоит рядом с лавой/огнём/магмой/кактусом (вода у грядки — норма, в отличие от шахты), не ломает ничего, кроме зрелого урожая
  и сорной травы над вспахиваемой клеткой.
- Итоги — как у `gather`: набрано — `SUCCEEDED`; иначе `FAILED` с числами и причиной, например «собрано 5 из 9 зрелых клеток;
  пересажено 5; не растёт ещё: 4; без места для духа: 0; нет семян: 0». Нет зрелого в радиусе — `FAILED` «зрелых посевов в
  радиусе R нет; растёт: n» (как «блоков не осталось» у `gather`: стратегу важно знать, что делать нечего). Нет мотыги, семян или
  муки — отказ **до** первого действия, мир не меняется.

Числа (предварительно): `FARM_RADIUS` 1..16, по умолчанию 8; `till.count` 1..256, по умолчанию 16; `plant_crop.count` 1..256, по
умолчанию 64; `bone_meal.count` 1..256, по умолчанию 16; радиус воды 4 — ванильное правило, проверяется GameTest (п. 13).

замечание, для каждого теста — подлог по существу (сломанное поведение при компилирующемся проекте
и красный тест); «на родителе не компилируется» доказательством не считается.

- [x] R1 [дефект] Правило «не топтать грядку» не проверяется (порядок давало сравнение `BlockCoord`,
  лучшая стоянка совпадала с `FROM`, сообщение про воду ложное). Нужна строка, где стоянка на пашне
  строго ближе земляной, а первой ожидается земляная.
- [x] R2 [дефект] Тест масштаба `Hydration`: счётчик считает только `contains`; перебор через
  `stream`/`iterator` даёт 0 обращений и проходит. `iterator()`, `size()`, `stream()` считают обход.
- [x] R3 [дефект] `FarmPlanner.cannotBeat` вычитает 3, а смещение стоянки доходит до √11 ≈ 3.32:
  ранний выход пропускает ближнюю цель. Константа выведена из досягаемости; свойство jqwik сравнивает
  с полным перебором без раннего выхода.
- [x] R4 [дефект] Пределы чтений в тестах брались из production (подними константу — тесты зелёные).
  Константы закреплены в тестах литералами с проверкой равенства.
- [x] R5 [дефект] «Клетка читается не более раза» не проверялось; кэш дублировался (свой в
  `FarmStandSpots`). Двойной кэш убран; тест «максимум на клетку = 1» на пересекающихся окрестностях.
- [x] R6 [дефект] Удаление `ringSafe(floor, …)` тесты не замечали; `FIRE`, `HAZARD`, `FALLING` не
  проверялись. Есть таблица видов опасности × уровень (у ног, у пола).
- [x] R7 [стиль] Оракул `HydrationProperties.bruteForce` был копией кода; переписан перебором множества
  воды с условием `|dx|≤4, 0≤dy≤1, |dz|≤4`.
- [x] R8 [стиль] Свойство `FarmTally` проверяло `text.contains(count)` («2» находится в «из 12»).
  Проверяются пары «метка: n» и связка «done из requested».
- [x] R9 [стиль] Порядок проверок: в `FarmStandSpots` досягаемость — до `canStand`; в `FarmPlanner`
  дешёвая проверка тайла — до `hydration.watered`.

## Стоимость в тике

- Планирование цели — один вызов `FarmPlanner` на клетку: остановка по приёму R4, чтения идут через `CachedSafetyView` (клетка читается один
  раз), обычно десятки; вода — один проход `BlockLocator` порциями ≤ 4 среза за тик и 162 обращений к множеству на кандидата.
- Ход скрипта — одно действие за тик (удар/вспашка/посадка/мука); подбор — один запрос сущностей раз в 10 тиков, только вокруг клетки;
  вложенных циклов «духи × клетки» нет.
