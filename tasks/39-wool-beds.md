# Чеклист 39. Шерсть и кровати (согласовано владельцем 17.10)

Владелец 17.10: согласовано всё, кроме установки кроватей — к ней вернёмся вместе со строительством домов.
Числа — данными (горячая таблица); логика простая, мелкие задачи доски, по выполнению открываются следующие.

Рецепт кровати: 3 шерсти одного цвета + 3 доски (верстак). Шерсть: стрижка, убитая овца (1), 4 нити → 1 шерсть.

## Гейт

- Загон есть и в нём ≥ 4 овец (`min_pen_sheep`). Пока меньше — только «развести овец» (пшеница, breed уже есть).
- Овец загона никогда не убиваем.

## Задачи доски (когда гейт выполнен)

1. «Сделать ножницы» — 2 железных слитка; доступна, когда есть железо.
2. «Постричь овец в загоне» — овцы с шерстью; повтор, когда шерсть отрастёт.
3. «Убить диких овец в округе» — вне поселения, радиус 48 (`wild_sheep_radius`), не больше N в сутки
   (`wild_sheep_per_day`); шерсть + баранина; только при ≥ 4 в загоне; выход наружу — по правилу «только группой».
4. «Шерсть из нитей» — когда нитей ≥ 8 (`string_threshold`), делать, пока остаётся запас 4 (`string_reserve`).
5. «Сделать кровать» — есть 3 шерсти одного цвета и 3 доски; пока кроватей меньше, чем духов.
6. ~~«Поставить кровать»~~ — позже, со строительством домов.

Цвета: сначала белая, остальные — когда набралось 3 одного цвета; красители пока не делаем.
Приоритет: спрос = число духов без кровати.

## Тесты

- Свойства на гейты: < 4 овец — только разведение; нити ≥ 8 → шерсть, запас 4 остаётся; кроватей ≤ духов;
  овцы загона не в целях убийства.
- GameTest: стрижка в загоне без убийств; дикие овцы вне загона — цель, овцы загона — нет; нити → шерсть;
  3 шерсти + 3 доски → кровать в инвентаре.
