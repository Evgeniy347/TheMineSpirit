# own-1 — `scripts/gametest.sh` работает в Git Bash на Windows

Источник: `todo.md` → «`scripts/gametest.sh` не работает в Git Bash на Windows (нет flock)».
Ветка `task/own-gametest-win`, каталог `F:\repos\minecraft\wt-own-gametest-win`.

## Проблема
`scripts/gametest.sh` держит замок через `flock -w 1800 -E 75`. В Git Bash на Windows команды `flock` нет:
скрипт падает с «flock: command not found», и GameTest на ПК приходится запускать в обход скрипта, без замка.
Тогда два исполнителя поднимают два сервера игры, машина уходит в swap, тесты флакают.

## Что сделать
1. В `scripts/gametest.sh`: если `flock` есть (Linux, domovoy), поведение не меняется.
2. Если `flock` нет, нужен запасной замок на `mkdir`. Создание каталога атомарно и в Linux, и в Windows.
   - Каталог замка `${THEMINESPIRIT_GAMETEST_LOCK:-/tmp/theminespirit-gametest.lock}.d`, внутри файл `pid`.
   - Ожидание до 1800 с (переменная `THEMINESPIRIT_GAMETEST_WAIT`, по умолчанию 1800), опрос раз в 2 с.
     Не дождались: те же две строки в stderr и код выхода 75, как сейчас.
   - Протухший замок (процесс из `pid` мёртв: `kill -0` не проходит) удаляется с сообщением в stderr, после этого
     замок берётся.
   - `trap` на EXIT/INT/TERM снимает замок, даже если gradle упал или запуск прервали Ctrl+C.
   - Код выхода `./gradlew runGameTestServer` возвращается без изменений.
3. Чтобы скрипт можно было тестировать без настоящего gradle, команду запуска задаёт переменная
   `THEMINESPIRIT_GRADLEW` (по умолчанию `./gradlew`).
4. Тест `scripts/testing/check-gametest-lock.sh` по образцу соседних `check-*.sh`, с фейковым gradlew
   (пишет время старта и конца в файл и спит 2 с). Запасной путь включается, если `PATH` не содержит `flock`
   (подложи каталог без него) или если задать `THEMINESPIRIT_GAMETEST_NOFLOCK=1`. Проверки:
   - два параллельных запуска не пересекаются по времени (второй стартует после конца первого);
   - протухший замок (каталог с pid несуществующего процесса) снимается, запуск идёт;
   - при ожидании 3 с (`THEMINESPIRIT_GAMETEST_WAIT=3`) и занятом живом замке выход 75;
   - код выхода фейкового gradlew (например, 3) возвращается как есть;
   - после выхода, в том числе после падения gradlew, каталог замка удалён.
5. Документация: в `docs/TESTING.md` поправь строку про `flock`: на Windows замок на `mkdir`, переменные выше.
   В `todo.md` пункт перенеси в «Сделано» с хэшем.

## Приёмка
- `bash scripts/testing/check-gametest-lock.sh` зелёный в Git Bash на ПК. Если есть доступ к domovoy, то и там.
- Реальный прогон на ПК: `bash scripts/gametest.sh` доходит до GameTest-сервера (одного запуска достаточно,
  можно прервать после старта; замок снимается).
- Тест сначала красный: на старом `gametest.sh` проверки замка падают. Достаточно разок проверить руками.

## Не трогать
Логику GameTest и `build.gradle`. Публикацию мода и перезапуск сервера не делать.
