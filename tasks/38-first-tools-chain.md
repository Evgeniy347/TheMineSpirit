# Чеклист 38. Цепочка «с нуля до инструментов» и белый список стратега (владелец 17.10)

Владелец 17.10: белый список стратега расширяем (acquire, craft, equip, withdraw); последовательность действий — ниже;
по ней — план покрытия тестами. Логика простая и воспроизводимая тестом.

## Последовательность (ваниль)

1. Срубить дерево → 4+ брёвна. 2. Брёвна → доски (в инвентаре 2×2). 3. 4 доски → верстак, поставить рядом.
4. Доски → палки. 5. Верстак: деревянная кирка, топор и лопата. 6. Деревянной киркой → булыжник (~11).
7. Каменные кирка, топор, лопата, меч. 8. 8 булыжника → печь, поставить. 9. Уголь (древесный в печи или жила) +
палка → факелы. 10. 2 сундука (по 8 досок), поставить. 11. Каменной киркой → железо → плавка → железные инструменты.

Владелец 17.10: верстак, печь и сундуки ставятся рядом (рабочий угол у базы); деревянная лопата — в шаге 5.

Уже есть: `acquire` (ResourceResolver строит цепочку), `StationPlacer` ставит недостающий верстак/печь; GameTest
`AcquireGameTests.*FromScratch*` — но верстак в них поставлен заранее (шаги 3 и 8 в игре не проверены).

## 38А. Быстрые тесты планировщика (JUnit/jqwik)

- От пустого инвентаря к деревянной кирке: цепочка минимальна, верстак (крафт + постановка) раньше кирки.
- Каменная кирка — только после деревянной (уровень инструмента); печь — раньше плавки; топливо — раньше плавки.

## 38Б. Стратег

- `agents/strategist/policy.json`: в белый список — acquire, craft, equip, withdraw (параметры и проверки плана для них).
- Сценарии: пустой инвентарь → план начинается с acquire кирки, а не с mine_vein; кирка есть → mine_vein допустим.

## 38В. GameTest цепочками (немного)

1. Только дерево рядом, верстака нет → дух делает и ставит верстак → деревянные кирка, топор, лопата в инвентаре.
2. Дерево + камень → набор каменных инструментов (кирка, топор, лопата, меч).
3. С нуля → печь поставлена рядом с верстаком, факелы сделаны (уголь древесный); сундуки — рядом же.
4. Доска «первые шаги» на арене: сундуки → верстак → инструменты по порядку; журнал доски — постановка, дух, итог.
