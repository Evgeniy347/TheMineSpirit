# Чеклист 56. Сцены на генерируемом мире, сокращение GameTest, логи воспроизведения (владелец 24.10)

Ревью процесса — `F:\repos\minecraft\oc-results\review-process-fable.md`. Решения владельца: выкладки не замораживаем,
«читов» этапа 1 нет; тесты ловят живые баги за счёт неплоского мира, а не числа сцен.

1. [ ] Генератор сцены: неплоский участок по сиду (холмы, низина, пещера под участком, деревья, вода, старые постройки
   поселения); сид пишется в лог теста; `scripts/test.sh gametest <пачка> --seed N` повторяет ту же сцену.
2. [ ] Сквозная сцена «этап 1» на генерируемом мире (≤ 6000 тиков): ровно, ограда цела и непроходима, хижина, шахта,
   факелы по плану, никто не застрял; падение → разбор → правка → перезапуск с тем же сидом.
3. [ ] Сокращение GameTest: таблица «механика → сцены», по 1–3 сцены на механику; укрупнять (дух выполняет ряд
   заданий) или переносить в unit; сторож числа сцен (не растёт). Сейчас ~1100 сцен.
4. [ ] Логи воспроизведения: `[incident]` и провал задания пишут всё для повтора — дух, задание, параметры, позиция,
   инвентарь, сид/снимок окрестности (структура NBT в папку мира) — чтобы сцену из живого мира загрузить в тест.
