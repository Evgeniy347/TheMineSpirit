# Чеклист 50. Приоритеты задач духов (владелец 22.10)

Владелец: «с приоритетами задач надо разобраться». В живом прогоне духи строили «гробы» 3×3 из брёвен вместо
инструментов и шахты, не работали задания минимального запаса, нет пути «уголь → факел». Сначала — разбор фактами
(как сейчас устроены доска, автозадачи, первые шаги, постоянные запасы и их приоритеты), затем правки.

1. [ ] Разбор: таблица всех источников задач (доска: первые шаги, evergreen/постоянные запасы, supply, загоны,
   ремонт; автозадачи интеллекта: урожай, плавка, сон, уборка; тактика) — кто ставит, условие, приоритет, что
   вытесняет что. Итог — в этот чеклист (короткая таблица) и вопросы владельцу, где порядок неочевиден.
2. [ ] Минимальный запас не сработал: в живом прогоне брёвна были, но заданий на доски, палки и деревянные
   инструменты не появилось. Найти причину фактами (лог/тест), починить: постоянный запас (доски, брёвна, палки,
   деревянный набор инструментов) поддерживается сам.
3. [ ] Порядок развития с нуля (решение владельца 21.10): первые инструменты → вход в шахту и спуск (чеклист 49) →
   уголь и булыжник в шахте → факелы → только потом постройки (укрытие 6×6 и т. д.). Тест на порядок первых шагов
   «пустое поселение → …».
4. [ ] Факелы: при получении первого угля сразу приоритет «сделать факелы» (и доставить факелы по необязательным
   клеткам света построек, чеклист 49 п.4).
5. [ ] Древесный уголь: как только поставлена печь — в приоритете пережечь пару брёвен в древесный уголь на факелы
   (если угля нет), топливо — доски/брёвна.
6. [ ] Невыполнимые задания (правило владельца): гейт по условию до выдачи уже есть для части автозадач (чеклист 48
   п.2) — проверить, что то же действует для доски и первых шагов; провал — инцидент в журнал и новое задание.
