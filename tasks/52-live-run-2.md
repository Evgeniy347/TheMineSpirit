Факты и логи — `tasks/live/run-2-incidents.md` (INC-23…28 и предложения к REST). Причину подтверждать логом или
красным тестом; правило владельца: дух не получает невыполнимых заданий, провал — `[incident]` и новое задание.

1. [x] INC-23: задания PENDING с назначенным духом не выдаются — духи простаивают. Причина: `issue` исключал
   держателя своего PENDING-тикета из выдачи остальных, даже когда тот на паузе кейса после провалов (REPAIR_TOOL) —
   все 4 духа ждали свои невыполнимые тикеты. GameTest `dispatch_OwnTicketPaused_SpiritTakesFreeTicket`.
2. [x] INC-24: REPAIR_TOOL без наковальни — вечный цикл FAILED→POSTED; гейт по наличию наковальни/материала.
   Сделано: `RepairWatch` ставит ремонт материалом только при наковальне у дома (точило — без станции); план идёт к
   дому перед `repair_tool`; `TaskStarter` не приписывает провал задачи доски своему занятию (unload/hunt «нет
   наковальни» — вытесненное занятие). GameTest `repair_NoAnvilAtHome_TicketOnlyAfterAnvil`,
   `starter_ForeignTaskFails_NotBlamedOnOwnScript`.
3. [x] INC-25: первые шаги застряли на LIGHTING (ждут torch×4), факелы никто не делает — связать с CRAFT_TORCHES/
   углём (чеклист 50 п.4–5).
   Причина: без угля и печи (CRAFT_FURNACE BLOCKED, INC-26) `TorchRules` не ставил ничего. Сделано: угля нет и
   пережечь нечего, а шахта есть — `torch:gather_materials` «добыть уголь» (`mine_vein coal`, acquire уходил в
   древесный уголь — журнал 05:49). Тесты `TorchRulesTests`, `plan_GatherCoal_MinesCoalVein`.
4. [x] INC-26: CRAFT_FURNACE BLOCKED «нужен верстак: рядом (16) нет», хотя верстак есть. Факты: верстак был в
   инвентаре spirit-2, крафтеры 1/5 его не имели, у места крафта (дом) не стоял. Сделано: нет верстака у места
   крафта — он ингредиент передачи (`TransferWatch`), его несёт дух-владелец; строка «открыт» — только при реальной
   постановке шага. GameTest `furnace_TableAtNeighbour_TransferredToCrafter`.
5. [x] INC-27: тактика дёргается DEFENSIVE↔GUARD_AREA при нуле врагов (как INC-3, другой триггер). Причина:
   свободному духу координатор ставит мирный пост (GUARD_AREA), занятого снимает (DEFENSIVE); интеллект то даёт,
   то снимает короткую работу — флип каждым циклом. Гистерезис: без врагов пост — после 200 тиков простоя
   (`CoordinatorTuning.CALM_POST_IDLE_TICKS`). GameTest `calm_NoEnemies_ModeDoesNotFlip`.
6. [x] INC-28: добыча камня не идёт — «в одиночку не ходят», `supply:stone` падает по кругу. Причина цикла:
   `mine_level_2` (выработка `dig_area`, материала не тратит) гейтился `stone ×32` → `supply:stone`; камень (не
   булыжник) добычей не получить. Уровень 2 — без гейта, уровень 3 — `cobblestone ×49` (пол 7×7 `fill`). GameTest
   `relevance_CraterBury_DetachesAndLevelTwoWithoutStoneGate`. «В одиночку не ходят» — отказ внешней работы MINE
   интеллекта: в группу идут только духи роли WORKER, их было меньше 2; см. QUESTIONS-52.
