## Что меняется в доске 35 (не переписывание, а переходы)

1. **TTL → проверка актуальности.** В35 задание живёт `ttlTicks` (по умолчанию 6000) и умирает молча по
   сроку; только ремонт и воронка изъяты через `hasNoTtl`. В2 срок жизни у всех заданий отменяется: у
   событийных и постоянных причинная связь проверяется при каждой пересборке — «воронка ещё есть? животное
   живо? забор ещё сломан?» — и потерявшие актуальность задание снимается с записи в журнал (не «умерло от
   старости», а «причина отпала»). Поле `ttlTicks` в `BoardTicket` убирается, таблица `ttl` в `board.json` —
   тоже; `hasNoTtl` и `DEFAULT_TTL_TICKS` (14 мест в 35bv) уходят.
2. **Удаление → «выполнено».** В35 `prune` снимает с доски `DONE`/`FAILED`/`CANCELLED` (в 35bv DONE запоминается
   в `completed`-кэше для зависимостей). В2 задание-постройка после выполнения **остаётся на доске** со статусом
   `DONE` — это отметка выполнения, по которой другие задания видят условие («загон построен», «уровень 1 шахты
   готов»). `prune` снимает только `CANCELLED` (отмена, снятие по актуальности) и вытеснение переполнения;
   `DONE` живёт до перезапуска (на диске в журнале — бессрочно). Кэш `completed` заменяется этим журналом.
3. **Зависимости — по состоянию «выполнено».** `dependsOn` (id заданий) дополняется зависимостью от
   постройки-уровня: `building:BUILD_MINE:1` — условие считается выполненным, если на доске есть `DONE`-задание
   этого кейса с этим уровнем или подтверждение из журнала прошлой сессии (п. 20).
4. **Приоритет — база + модификаторы.** В35 `BoardRules.priorityOf(case)` возвращает одно число кейса. В2
   итог = база кейса + сумма модификаторов ситуации («пово­сили/понизили»), всё — числа из `board.json`;
   итог зажимается в `[0, MAX_PRIORITY]`.
5. **Первые шаги → уровни построек.** `FirstStepsPlan` (одна цепочка) остаётся для самой первой застройки;
   дальше развитие — не новая цепочка, а уровни: каждая постройка имеет уровни, следующий доступен, когда
   выполнен предыдущий и есть ресурсы (гейт). Шахта — эталон: 1 `dig_descent` (проход 1×3 вниз), 2 расширение
   тоннеля, 3 ступеньки, 4 рельсы и вагонетка.
6. **Одно животное → циклы по видам.** `AnimalLifecycle` в 35bv — одна машина на всю доску (один цикл за раз).
   В2 — параллельные циклы по видам (коровы, свиньи, куры…), у каждого свой загон и лимит 4 животных.
