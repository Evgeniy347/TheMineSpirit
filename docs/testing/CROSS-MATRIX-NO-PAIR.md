# Непересекающиеся пары механик

Пары из `docs/testing/CROSS-MATRIX.md`, отмеченные `н/п`: у механик нет общего объекта, узла графа и
состояния на входе — одна не создаёт и не читает факты другой. Общая ходьба и общий склад работой пары
не считаются; каждая строка — короткое обоснование. Пары ведутся только по «Н», «Е» и «Ч» в матрице.
