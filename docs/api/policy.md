### GET /v1/policy/unprotect

Список разрешённых областей: `{"areas":[…]}`. Область — ресурс **UnprotectArea**. Список переживает
перезапуск сервера (сохраняемые данные мира). Пустой список — `{"areas":[]}`.

### POST /v1/policy/unprotect

Выдать разрешение: внутри куба дух не считает блоки постройкой игрока (осторожная защита вне области
и для чёрного списка / защищённых зон сохраняется). Тело:

```json
{ "request_id": "3f1c2d3e-0000-4000-8000-000000000000", "dimension": "minecraft:overworld",
  "min": [10, 64, 10], "max": [17, 71, 17], "granted_by": "игрок",
  "reason": "убери постройку в координатах", "ttl_seconds": 3600 }
```

- `request_id` — обязателен, UUID; повтор с тем же телом возвращает прежнюю область, с другим — 409 `conflict`;
- `dimension` — обязателен, один мир; `min` и `max` — обязательные массивы из трёх целых `[x, y, z]`,
  углы можно менять местами;
- `granted_by` и `reason` — обязательные непустые строки (кто попросил и зачем);
- `ttl_seconds` — необязателен, по умолчанию `0` — бессрочно; иначе срок жизни в секундах;
- лишнее поле — 400 `invalid_request` с именем поля.

Предел объёма области — из данных `data/theminespirit/policy/protection.json` → `maxUnprotectVolume`
(по умолчанию 4096 блоков); область больше — 400 с фактическим объёмом и пределом. Область, пересекающая
защищённую зону сервера (`policy.protectedZones`), отвергается: защищённую зону снимают правкой конфига,
а не разрешением. Число разрешений — не больше 64.

Ответ `201` — область целиком плюс `request_id` клиента. Идём через `IdempotencyCache`, как задачи духа.

### DELETE /v1/policy/unprotect/{id}

Снять разрешение: `200` с `{"id":…,"removed":true}`; защита области возвращается сразу. Неизвестное
разрешение — 404 `not_found`.
