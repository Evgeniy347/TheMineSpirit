### GET /v1/world

Правдивая картина участка на входе графа: лишнее, рельеф и повреждённые постройки. Читается из последнего прогона
графа (раз в минуту), мир на запросе не сканируется.

```json
{ "strays": 37, "strayGroups": 5, "pits": 12, "mounds": 3, "natural": 3263,
  "hanging": 2, "damagedBuildings": 4, "unknown": false,
  "groups": [
    {"type": "oak_fence", "position": [181, 64, 517], "blocks": 12, "builder": null}
  ],
  "buildings": [
    {"id": "warehouse", "damage": 7, "unknown": false},
    {"id": "orchard_oak", "damage": 2, "unknown": false}
  ] }
```

- `strays` — блоков рукотворного лишнего вне клеток плана внутри ограды; `strayGroups` — связных кусков;
- `groups` — куски: тип (преобладающий блок), начало, число блоков и строитель из журнала (`null` — записи нет);
- `pits` — клеток ям (на лотах и явные ямы от добычи духа по учёту изменений), `mounds` — блоков насыпей
  **на лотах** относительно отметки площадки, `natural` — блоков природного рельефа вне лотов (не работа),
  `hanging` — находок висящего (кроны, заборы без опоры);
- `damagedBuildings` — построек плана с повреждениями по аудиту схемы; `buildings` — их id, урон и признак
  неизвестности;
- `unknown: true` — часть колонок в незагруженных чанках: числа неполные, этап по такому миру не закрывается.

Блоки, поставленные игроком, в лишнее не попадают (учёт установок по клетке в сохранении мира). Вне ограды
лишнее не сносится; это политика `protection.json → strays`, `demolishStrays`, `straysInsideFenceOnly` в данных.
