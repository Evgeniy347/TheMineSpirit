# Объяснение решений графа

Граф раз в минуту пишет в лог строку `[graph] решение: дух → работа (вес), следующий кандидат и почему не он`.
Тот же снимок отдаётся REST — наблюдателю и стратегу, чтобы решение можно было проверить без чтения лога.

## GET /v1/graph/decisions

Ответ — последний снимок, посчитанный тактикой (не пересчитывает граф и не меняет доску).

```json
{
  "tick": 28655009,
  "decisions": [
    {"spirit": "spirit-1", "task": "make:dirt", "weight": 42, "feasible": true,
     "next": "chop_oak_log", "next_weight": 38, "why": "вес ниже на 4"},
    {"spirit": "любой", "task": "building:streets", "weight": 30, "feasible": false,
     "next": "make:planks", "next_weight": 20, "why": "неосуществим сейчас: нет материалов или инструмента"}
  ]
}
```

| Поле | Что значит |
|---|---|
| tick | тик сервера, на котором граф принял решение |
| spirit | дух, которому адресована работа, или «любой» — работу возьмёт свободный |
| task | id работы графа (make:dirt, building:streets, event:…) |
| weight | вес работы после всех поправок выбора |
| feasible | работа выполнима сейчас (материалы, инструмент, условия) |
| next | следующий кандидат того же прогона |
| next_weight | его вес |
| why | почему выбран не он: ниже вес, нет материалов/инструмента, кандидатов больше нет |

Если граф ещё ни разу не считался, ответ — пустой список решений с тиком 0.
