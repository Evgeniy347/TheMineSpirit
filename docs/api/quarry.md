# Места добычи земли и песка

Место выбирает стратег (или игрок) по REST; граф только использует установленное место, а мод сам не ищет
и не переносит его. Решение владельца 06.11: мод даёт оценку, выбор — за стратегическим ИИ.

## Ресурсы

- **QuarrySite** — место добычи: `resource` (`dirt`, `sand`, `snow`), `point` (`{x,y,z}`), `radius` (1..16),
  `biome`, `reserve` (добываемый запас), `dug` (выкопано), `remaining_percent`, `state`
  (`active`/`low`/`empty`/`unset`), `path` и `route` (постройки тропы и точки), `path_built`, `route_built`.
  Состояние `low` — остаток меньше 10% начального запаса.
- **QuarryCandidate** — область поиска: `point`, `radius`, `reserve`, `path` (длина пути от поселения),
  `value` (запас на блок пути в тысячных), `biome`. Список отсортирован по выгодности.

Запас считается по правилам копания: карьер слоями (до 4 блоков на колонку), плавное углубление к центру
(соседние колонки отличаются не больше чем на блок), не ниже уровня воды, если вода рядом (дно вровень с водой),
только вне участка и плана поселения, блоки игроков не трогаются. Копают подряд идущий ресурс сверху:
первый камень останавливает колонку.

## Поиск

`GET /v1/quarry/search?resource=dirt&min=128&max=512`

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `resource` | — | `dirt`, `sand` или `snow` |
| `x`, `y`, `z` | центр поселения | базовая точка; задаётся вся тройка или ничего |
| `min`, `max` | 128, 512 | диапазон расстояний в блоках |

```json
{"resource":"dirt","min":128,"max":512,"candidates":[
 {"point":{"x":210,"y":64,"z":-40},"radius":4,"reserve":164,"path":250,"value":656,"biome":"minecraft:plains"}]}
```

## Установка и снятие

`POST /v1/quarry/site` (или `PUT`, тело то же):

```json
{"resource":"dirt","x":210,"y":64,"z":-40,"radius":4,"biome":"minecraft:plains","by":"strategist"}
```

`by` — `strategist` или `player`; `by: "graph"` отвергается: граф место не выбирает. Ответ — статус места.
Область без добываемого ресурса не ставится (400): тропа не ведёт в пустую яму.

`DELETE /v1/quarry/site?resource=dirt` — снять место; ответ `{"resource":"dirt","state":"unset"}`.

## Статус

`GET /v1/quarry/status` — все ресурсы, включая `unset`:

```json
{"sites":[
 {"resource":"dirt","state":"low","reserve":9,"dug":91,"remaining_percent":9,"low":true,
  "point":{"x":210,"y":64,"z":-40},"radius":4,"biome":"minecraft:plains","initial_reserve":100,
  "path":"path_plains","route":"route_dirt","path_built":true,"route_built":true}]}
```

Стратег читает статус: при `low`, `empty` или `unset` он вызывает поиск и ставит лучшую выгодность.
Оповещение в чат о малом запасе — не чаще раза в 5 минут на ресурс; флаг `low` в статусе обновляется всегда.
