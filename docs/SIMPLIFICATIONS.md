# Упрощения механик (согласовано владельцем 18.10)

Правило: дух может «читерить» в досягаемости и подборе, если это убирает класс багов; числа — данными;
действие всегда строго ограничено целевыми блоками/предметами/существами (чужое не трогает). Каждое такое
упрощение описывается и ЯВНО согласуется с владельцем до реализации. Застревание исполнителей на механике —
повод предложить владельцу упрощение (следит главный агент).

## Согласованные упрощения

1. Подбор «магнитом»: дроп в радиусе R (данными) сам попадает в инвентарь при наличии места; только свободные
   дропы — не рамки, не предметы игрока, не брошенные им недавно (защита данными).
2. Контейнеры и станции в радиусе: сундук, верстак, печь, наковальня и т. п. — работа без точного подхода,
   в досягаемости 3 по горизонтали / 15 вверх, без требования прямой видимости.
3. Добыча с места: встал у жилы — ломает видимую руду этой связной жилы (предел числа — данными); куча и копка
   области — только открытые блоки, с нескольких стоянок по правилу досягаемости; без столбов и спусков ради
   досягаемости; закрытую руду вне досягаемости дух обходит стоянкой.
4. Ловля животных: поводок или приманка (животное идёт за духом с кормом); «кольцо» из блоков не строится.
5. Отход без стройки: дух не ставит столбы и баррикады; уходит к дому, союзнику, игроку или воде.
6. Переправа через воду: вплавь или по дну; мост из переправы убран (`bridge` — отдельный скрипт).
7. Рыбалка: ожидание у воды N секунд (данными) → улов по ванильной таблице лута, без поплавка.
8. Ферма: вспашка, посадка и сбор с нескольких стоянок по правилу досягаемости, без обхода каждой грядки.
9. Декор в схеме сада: цветы помечены необязательными (`~`) и не блокируют постройку; `dirt_path` топчется
   лопатой по траве или земле в клетке схемы (нет лопаты — сначала лопата).
10. Снос старых заборов и калиток — только в полосе ограды поселения (28.10); замена ставится на y+1 по плану.
    Вне полосы и для дверей, табличек и прочего из `protection.json → deny` защита прежняя.
11. Декор одним действием (вопрос 14, `settlement/decisions.md`): горшок с цветком, нажимная плита на заборе,
    фонарь на цепи, зажжённая свеча; предметы тратятся как обычно.

Телепорт при застревании отменён владельцем 02.11: возврат только ходьбой, обход — маршрутом.

## Порядок

Каждый пункт — отдельная небольшая задача: JUnit на правило (числа из данных, ограничение целями) и GameTest
сценария; старые тесты переделываются по существу, без ослабления. Сложная логика удаляется вместе с тестами
только если механика действительно убрана владельцем.
