# Память неудач графа

Память (`GraphFailureMemory`) не ставит задач: она даёт графу **состояние** «эта цель этого узла плоха».
Запись — по ключу «узел + цель» (`x,y,z`); тик, причина и число провалов живут в памяти сервера
(после перезапуска пусто — это допустимо: мир и доска пересчитываются заново).

## Что делает провал

| Причина | Действие |
|---|---|
| `CHUNK` | не штраф: чанк подгружается, задание повторяют |
| `NO_PATH`, `NOT_REACHED` | цель помечается недостижимой; узел помнит её отдельно от других целей |
| `NO_MATERIAL` | не штраф узла: нехватка входа — работа снабжения (её видит `GraphLack`) |
| `OTHER` | мягкий штраф узла весом `failureSoft` |

## Цель и узел

- Первая же недостижимая цель **исключается из выбора**: доска берёт другую цель того же узла
  (`FailureTargets`, радиус `failureTargetRadius` отделяет ствол от соседнего дерева). Если живы все цели,
  повторяют ближайшую — честно, без молчаливого простоя.
- Узел целиком штрафуется, только когда провалились **разные** цели: их число не меньше `failureTargets`.
  Один недоступный ствол не снимает рубку везде.
- Штраф узла: `failureBackoff ^ min(вес, 3)`, где вес — сумма затухающих провалов недостижимых целей плюс
  `failureSoft ×` вес прочих. Дорога удлиняется по `farTrip` только у оштрафованного узла (или при плохой
  погоде), а не после любого единичного провала.
- Успех по цели (`succeed`) удаляет её запись: счётчик начинается заново. Узлы жизни не штрафуются:
  меняется способ (помощник, выход, другой путь события), а не вес.

## Затухание

Вес записи = сумма `0.5 ^ (возраст / failureHalfLife)` по провалам. Окно не обрывается: штраф плавно
уходит, запись удаляется при весе ниже `0.001`. Поэтому редкий старый провал не держит узел вечно, а
частый свежий — держит. Штраф на прогон плана считается один раз: агрегат узлов кэшируется, задачи только
читают его (стоимость — записи памяти плюс задачи, не их произведение).

## Параметры (`graph.json` → `choice`, подбираются на GPU)

| Параметр | По умолчанию | Смысл |
|---|---|---|
| `failureBackoff` | `0.5` | множитель веса за один «вес провала» |
| `failureTargets` | `2` | сколько разных целей должны провалиться, чтобы штрафовать узел |
| `failureHalfLife` | `3000` | полураспад штрафа, тиков |
| `failureSoft` | `0.5` | доля веса провала `OTHER` |
| `failureTargetRadius` | `6` | радиус, в котором цель считается той же |

Python-модель (`tools/graph-gpu/graph_model.py`) повторяет эти правила; сверка — `test_conformance.py`.
