# Модели-исполнители

Модель задаётся `OPENCODE_MODEL=<провайдер>/<модель>` для `scripts/opencode-task.sh` (ПК) или аргументом
`scripts/opencode-start.sh` (сервер).

## Что используем (на 19.10)

| Модель | Где | Применение |
|---|---|---|
| `deepseek/deepseek-flash` | ПК, платная с баланса владельца, контекст 1 млн | основной исполнитель ПК, 4–6 сессий |
| `opencode-go/deepseek-v4.1-flash` | сервер, подписка Go | основной исполнитель сервера, 2–3 сессии |
| `opencode-go/*` прочие | по списку владельца (Muse 1.3/1.2, MiMo-V2.6-Flash, MiMo-V2.5) | только из списка |
| Claude Opus/Sonnet (Agent) | ПК, лимиты плана Max | по решению владельца; большие связные задачи (`docs/LEAD-AGENT.md`) |
| `deepseekbridge/*-web` (мост) | ПК | только по команде владельца |

Бесплатные `opencode/*-free` с ПК упираются в лимит на клиента, Zen free из domovoy недоступны — не использовать.

## DeepSeek API

Баланс — `GET https://api.deepseek.com/user/balance` с ключом из `~/.local/share/opencode/auth.json` (ключ не печатать).
Цены за 1 млн токенов, $ (вне пика / пик): вход из кэша 0.003/0.006, мимо кэша 0.15/0.30, выход 0.60/1.20.
Пик (цена ×2): пн–пт 06:00–09:00 и 11:00–15:00 по ПК; выходные — вне пика. У агента ~95–98 % входа из кэша.
Замер 16.10: ~1.3 ¥/ч на сессию. Баланс ≤ 1 ¥ — сессии останавливать (на ошибке оплаты надзор крутит перезапуски).

## Контекст и сжатие

Модели с контекстом 200 тыс. сжимают разговор каждые 20–60 шагов и теряют задание — им только короткие задачи.
Большие задачи — модели с ~1 млн. Задание и прогресс в любом случае — `TestResults/task.md` и `progress.md`.
Claude Opus за ~3 ч плотной работы набрал ~980 тыс. токенов и остановился («Prompt is too long», 18.10): ~60 %
ушло на чтение кода (`cat`/`grep` без индекса codegraph), ~35 % — на запись файлов целиком, тесты ~2 %.

## Качество на реальных заданиях (сводка)

- Типичные ошибки слабых моделей: отчёт «всё сделано» без коммитов или со старыми хэшами (сверять с `git log`),
  тесты, которые не краснеют (требовать подлог по существу), ослабление пределов под факт, склейка пунктов,
  `--amend`. GigaChat (кроме 3 Ultra на крошечных задачах) — не годится.
- Сильнее всего на больших задачах (по ревью 13–16.10): muse-spark, longcat (короткие и средние), deepseek-web;
  планировщик чеклистов — big-pickle. С 17.10 основные — deepseek-flash (ПК) и Go deepseek-v4.1-flash (сервер):
  ветки обычно проходят приёмку, частые проблемы — флеки соседних пачек и молчание провайдера (лечит надзор).
- Opus (18.10): один связный коммит на 153 файла без конфликтов и без вмешательства, но упёрся в контекст.
