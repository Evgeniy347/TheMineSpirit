# Соглашения кода

## Логика без игры — в `core`

- `com.theminespirit.core` не импортирует `net.minecraft`, `net.neoforged`, `com.mojang` (сторож `CoreIsolationTests`)
  и проверяется чистым JUnit за секунды. Новый класс, которому не нужен мир, идёт в `core` с тестами в том же коммите.
- Код, которому нужна игра, — тонкий адаптер: собрать данные из мира → чистая функция из `core` → применить
  результат. Решение «что делать» — чистая функция, а не состояние с кэшем.
- Числа геймдизайна — данными (`src/main/resources/data/theminespirit/…`, горячая перезагрузка — `docs/HOT-RELOAD.md`).

## Класс делает одно дело

Лимита строк нет, есть симптомы — любой означает «раздели класс до изменения»:
- две независимые секции с разными существительными; поля распадаются на группы для разных методов;
- метод с 3+ boolean-флагами, описывающими, КАКОЙ объект пришёл (нужен тип/стратегия/enum), или с 8+ параметрами
  (нужен объект-параметр) — кандидат в сторож, `tasks/45`;
- одна и та же лестница `instanceof`/сравнений с `Blocks.X` больше чем в одном методе: тип решается один раз на слой
  и превращается в данные или вызов метода (спросить объект → интерфейс → реестр обработчиков → enum возможностей);
- две почти одинаковые семьи методов; трижды повторённая настройка объекта (нужен конструктор/builder).

Метод — одна работа, ориентир ~40 строк. Фича не добавляется в класс с зоной другой фичи — новый класс.
Интерфейс — только на внешней или платформенной границе; `Function`/`Supplier` в production API ради тестов — нет.

## Комментарии

Смысл — в имени и тесте. Причина-ограничение Minecraft/библиотеки — только с меткой `// mc:` или `// lib:`
(сторож `ProductionCommentGuardTests`).

## Сборка

- `-Xlint:all -Werror`: предупреждение — ошибка; `@SuppressWarnings` — точечно, с причиной рядом.
- Версии зависимостей — только в `gradle.properties` (менять — решение пользователя). `src/generated/` — только datagen.
- Сторонняя библиотека объявляется трижды: `implementation`, `additionalRuntimeClasspath`, `jarJar` (образец — Jackson
  в `build.gradle`); без второго падает dev-запуск, без третьего — сервер игрока.

## Производительность

Код идёт в серверном тике (20 раз/с) на мирах с тысячами чанков и сущностей. Вложенный цикл по сущностям/блокам,
пересборка коллекции на каждом шаге, повторный поиск по миру — дефект. Правка горячего пути (тик, события,
генерация) — с тестом на масштаб, который считает операции, а не миллисекунды. Медленное в своей зоне — чини сразу,
в чужой — строка в отчёте с числом.

## Ошибки

Тихий fallback — авария: не глотать исключения и не подставлять умолчание молча (сторож `SilentCatchGuardTests`).
Сообщение об ошибке называет, что сломалось и что проверить.

## Файлы

- Исходники — UTF-8 без BOM; `*.sh` — LF, `*.bat` — CRLF и ASCII (`.gitattributes`). После `sed -i` проверь
  `git diff --stat`. Перед созданием файла проверь, что имя свободно.
- Временное — только в `temp-scripts/` и `TestResults/` (игнорируются Git, не `git add -f`); удалять только своё.
  Постоянные скрипты — в `scripts/` со строкой в README.
