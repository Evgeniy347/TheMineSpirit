# Публикация мода

## Главное правило

**Публикация мода и перезапуск сервера выполняются ТОЛЬКО ПО ПРЕДВАРИТЕЛЬНОМУ
СОГЛАСОВАНИЮ С ПОЛЬЗОВАТЕЛЕМ.** Агент не запускает публикацию и не перезапускает сервер
самовольно. Скрипт `scripts/publish.sh` тоже требует подтверждения и без него ничего не меняет.

## Что делает `scripts/publish.sh`

Единственное каноническое место логики публикации. Шаги:

1. требует согласования (интерактивное подтверждение; см. ниже);
2. собирает мод: `./gradlew --quiet build`;
3. находит ровно один `build/libs/theminespirit-*.jar`, исключая `-sources`/`-javadoc`;
4. проверяет размер jar (защита от пустого/битого артефакта);
5. делает снимок мира через `$SERVER_DIR/scripts/snapshot.sh`, если тот есть;
6. останавливает сервер, если активна tmux-сессия `minecraft`;
7. удаляет прежние `$SERVER_DIR/mods/theminespirit-*.jar` и кладёт новый jar;
8. запускает сервер обратно, если он работал.

Сервер по умолчанию — `/opt/minecraft/server`, переопределяется переменной `SERVER_DIR`.

## Гейт согласования

При обычном запуске скрипт печатает предупреждение, что публикация и перезапуск выполняются
только по согласованию, и просит ввести `y`/`yes`/`да`. Любой другой ответ (в том числе Enter)
прерывает работу с ненулевым кодом, **не меняя ничего**.

Флаг `-y`/`--yes` означает, что согласование уже получено: он пропускает вопрос и предназначен
для осознанного запуска после разговора с пользователем.

## Примеры вызовов

```bash
# Обычный запуск: спросит подтверждение.
scripts/publish.sh

# Показать план и ничего не менять.
scripts/publish.sh --dry-run

# Согласование уже получено — без вопроса.
scripts/publish.sh --yes

# Установить jar, но не перезапускать работающий сервер.
scripts/publish.sh --no-restart

# Сочетания: тихий запуск без перезапуска.
scripts/publish.sh -y --no-restart
```

## Предусловия

- Сервер установлен в `/opt/minecraft/server` и им управляют `scripts/start.sh`/`stop.sh`.
- Сервер живёт в tmux-сессии `minecraft` (задано в `server/scripts/common.sh`).
- Для проверки команд `/spirit` в игре нужен статус оператора (`op`).
- `snapshot.sh` коммитит и пушит мир в git сервера; если он отсутствует, шаг пропускается.

## Если что-то пошло не так

- **Сборка упала** — публикация не начинается, сервер не трогается; правь код и повторяй.
- **jar не найден или их несколько** — скрипт останавливается до установки; проверь `build/libs/`.
- **Упал `stop.sh`/`start.sh`** — смотри `logs/latest.log` сервера и консоль
  `server/scripts/console.sh`.
- **Откат мода** — положи в `$SERVER_DIR/mods/` прежний jar (удалив текущий
  `theminespirit-*.jar`) и перезапусти сервер. Мир откатывается из git сервера:
  `git log`/`git checkout` в `/opt/minecraft/server` (по правилам сервера).
- **Любой сбой** — повторная публикация после починки безопасна: скрипт сам удаляет старые jar.
