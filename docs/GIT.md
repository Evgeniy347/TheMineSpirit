# Git

## Текущий режим

- Работа — прямо в `main` клона `the-mine-spirit/`. Отдельная ветка, git worktree или исполнитель — только по
  отдельному решению владельца.
- Старые обёртки `../oc-results/self-merge.sh`, `lead-merge.sh` и `publish-main.sh` не использовать.
- Публикация не является частью коммита или слияния. Автоматический push/publish из обёрток запрещён.

## Коммит

- Коммит — законченный блок работы, а не каждый шаг.
- Перед коммитом: `git status --short`, `git diff`, `git diff --cached`.
- В индексе не должно быть чужих изменений. Не снимать их со staging: остановиться и согласовать коммит.
- Добавлять только свои точные пути. После коммита — `git log -1 --stat`.
- Агент коммитит по правилам задачи. **Push — только по прямой просьбе владельца.**

## Сообщение коммита

Формат: `<тип>: <описание по-русски>`.

Типы: `feat` — новое поведение, `fix` — исправление, `test` — только тесты, `refactor`, `docs`, `chore`.
Для `feat:`/`fix:` с production-кодом обязательны изменения тестов. Формат и это правило проверяет `commit-msg`.

Хук `pre-commit` запускает `scripts/test.sh unit --changed`, если в коммите есть `src/` или сборка.
Красный прогон — отказ. `--no-verify` и отключение хуков — только по прямому указанию владельца.

## Запрещённые команды

Уничтожают незакоммиченную работу или историю:

- `git stash`, `git reset --hard`, `git clean`;
- `git checkout`/`restore` без пути или с путём к чужим правкам;
- `git commit --amend`, `rebase`, любая перезапись коммитов;
- force-push и push в main/master без явного разрешения владельца.

Ошибка исправляется новым коммитом. Посмотреть закоммиченное — `git show HEAD:путь`.
Запрет перезаписи истории держат хуки `reference-transaction` и `pre-rebase`
(`scripts/testing/check-history-hooks.sh`).

## Удаление файлов

Удалять только свои файлы, проверив путь. Удаление — одним коммитом со всеми ссылками на файл
(`README.md`, `AGENTS.md`, `docs/`).

## Публикация

`scripts/publish.sh` и перезапуск сервера — только по согласованию с владельцем
([docs/PUBLISH.md](PUBLISH.md)). Успешный коммит сам по себе не разрешает push, публикацию или перезапуск.
