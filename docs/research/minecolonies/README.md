# Механики MineColonies и Structurize — карта для нас

Разбор механик ближайшего аналога нашей колонии: как устроены стройка по схемам, шахта, карьер, лес,
ферма, доставка, навигация, охрана, интерфейс и данные. Цель — не повторить разбор работ/склада/экономики
([colony-economy/](../colony-economy/README.md)), а добрать **механику мира**: что именно делает работник
руками и как это описывается данными.

Дата анализа: 2026-11-09. Наш проект — `The Mine Spirit`, NeoForge 1.21.1 / Java 21, ядро
`com.theminespirit.core` без импортов Minecraft; правила модели — [docs/ARCHITECTURE.md](../../ARCHITECTURE.md).

## Как читать

- Пути даны от корня соответствующего клона; классы — только ориентиры для навигации, не образец для копирования.
- «У нас» — сверка с нашим кодом через codegraph; названы наши классы и узлы графа.
- «Идея» — что именно переосмыслить и куда положить; «оценка» — S (≤1 дня), M (2–4 дня), L (> недели)
  по объёму правок и тестов, а не по красоте.
- Код, схемы, текстуры и имена MineColonies/Structurize в репозиторий не переносятся (GPL/ARR), см.
  [license.md](license.md). Все идеи ниже — пересказ алгоритмов своими словами.
