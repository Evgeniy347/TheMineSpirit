# Приложение к graph-ideas: таблицы идей

Основной документ — [graph-ideas.md](graph-ideas.md). Здесь полные списки, чтобы отчёт не превышал предел.
Обозначения: **этап 1** — фундамент и выживание, **этап 2** — экономика, оборона, ремонт, **этап 3+** — торговля,
Нижний мир, Энд, автоматизация, красота. Цена — порядок работы на пересборку; `кэш` — дорогой скан реже.
Действие: `есть` — скрипт уже есть, `частично` — есть сторож/билет без полного действия, `TODO` — нужна заглушка.
